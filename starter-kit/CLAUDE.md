## Команды
- `pnpm install` — установка зависимостей
- `pnpm dev` — dev-сервер
- `pnpm test` — все тесты; `pnpm test path/to/file.test.ts` — один файл (предпочтительно)
- `pnpm lint` / `pnpm typecheck` — обязательно перед коммитом

## Архитектура
- `src/routes/` → `src/services/` → `src/repositories/` — слои не перепрыгивать
- Общие типы — `src/types/`
- Конфигурация — только через `src/config.ts`, не читать `process.env` напрямую

## Стиль кода
- TypeScript strict, без `any`
- Именованные экспорты, без default export
- Ошибки — через классы из `src/errors.ts`

## Workflow
- Для задач сложнее одного файла — сначала план
- Сначала тест, потом реализация; после изменений запускай релевантные тесты
- Коммиты — Conventional Commits (`feat:`, `fix:`, `refactor:` ...)
- Ветки: `feature/<кратко>`, `fix/<кратко>`

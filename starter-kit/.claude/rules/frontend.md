# Правила для фронтенда

<!-- Пример. Адаптируйте под свой стек. -->
- Сначала ищи готовый компонент в `src/components/ui/`, новый создавай только при отсутствии.
- Стили — только через дизайн-токены, без «магических» цветов и отступов.
- Доступность: у интерактивных элементов есть фокус, aria-label там, где нет текста, alt у изображений.
- Изменения UI проверяй визуально (скриншот через браузерный MCP) на 375px и 1280px.

# Правила для API

<!-- Пример. Адаптируйте под свой стек. -->
- Каждый эндпоинт валидирует вход схемой (zod / pydantic) до бизнес-логики.
- Ошибки возвращаются в едином формате: `{ "error": { "code": "...", "message": "..." } }`.
- Никакой бизнес-логики в роутерах — только вызов сервиса.
- Любое изменение публичного API — обновить OpenAPI-спеку и добавить запись в CHANGELOG.
- Пагинация — `?page=&limit=`, `limit` ≤ 100.

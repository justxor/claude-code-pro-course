# Правила для тестов

- Структура: Arrange → Act → Assert, один сценарий — один тест.
- Имена тестов описывают поведение: `returns 404 when task does not exist`.
- Моки — только для внешних систем (сеть, время, файловая система). Свой код не мокаем.
- Никаких `sleep`: используй фейковые таймеры и явное ожидание.
- Не ослабляй проверки, чтобы тест прошёл. Если поведение изменилось намеренно — скажи об этом явно.

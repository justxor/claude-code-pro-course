# Onboarding

Цель — за 10 минут дать человеку рабочую ментальную модель проекта.

1. **Одним абзацем:** что это за продукт и для кого.
2. **Карта:** дерево ключевых директорий (до 15 строк) с пояснением каждой.
3. **Запуск:** установка, dev, тесты, один тест — проверь по CLAUDE.md/package.json/Makefile.
4. **Главные потоки:** 2–3 ключевых сценария (например, «запрос → ответ», «фоновая задача») — путь по файлам.
5. **Грабли:** неочевидные места, соглашения, то, что легко сломать.
6. **Кто что знает:** по `git log` — самые активные авторы по областям (только имена из истории).
7. **Первая задача:** предложи 3 небольшие задачи для знакомства (good first issue), от простой к сложной.

Пиши кратко, со ссылками `файл:строка`. В конце спроси, какую часть разобрать подробнее.

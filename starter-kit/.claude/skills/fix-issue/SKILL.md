# Fix issue #$ARGUMENTS

1. `gh issue view $ARGUMENTS` — прочитай issue и комментарии.
2. Найди релевантный код. Кратко опиши первопричину.
3. Создай ветку `fix/$ARGUMENTS-<кратко>`.
4. Напиши тест, который воспроизводит проблему, убедись, что он падает.
5. Исправь минимально необходимым изменением. Запусти тест и соседние тесты.
6. Прогони линтер и проверку типов.
7. Коммит: `fix: <описание> (closes #$ARGUMENTS)`.
8. Спроси, открывать ли PR (`gh pr create`).

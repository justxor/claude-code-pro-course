# Write tests

Цель: $ARGUMENTS

1. Найди тестовый фреймворк и 1–2 существующих теста рядом — повторяй их стиль, структуру и расположение.
2. Прочитай тестируемый код. Составь список сценариев:
   - основной (happy path)
   - граничные значения (пусто, 0, отрицательные, очень большие, unicode)
   - ошибки и исключения
   - взаимодействие с зависимостями (моки — только для внешних систем)
3. Покажи список сценариев одной строкой каждый, затем напиши тесты.
4. Запусти только новые тесты. Если тест падает из-за бага в коде — НЕ подгоняй тест, а сообщи о баге.
5. Итог: сколько тестов, что покрыто, какие баги найдены.

# Лаба 5. Субагент-ревьюер и параллельное исследование

**Цель:** научиться делегировать, экономя контекст основной сессии.

## Часть A — ревьюер

1. Скопируйте агентов из [`starter-kit/.claude/agents/`](../starter-kit/.claude/agents/), выполните `/agents`.
2. Внесите изменение в код (или используйте учебный проект с намеренными багами).
3. ```
   > попроси code-reviewer проверить незакоммиченные изменения
   ```
4. Сравните: попросите основную сессию «проверь сама себя». Кто нашёл больше?

## Часть B — параллельное исследование

1. Выполните `/context`, запишите заполнение.
2. ```
   > Запусти 3 субагента параллельно: (1) как устроена аутентификация,
     (2) где и как логируются ошибки, (3) какие части кода не покрыты тестами.
     Сведи результаты в таблицу.
   ```
3. Снова `/context`. Сравните с тем, если бы основная сессия читала все файлы сама.

## Часть C — свой агент
Создайте агента под вашу задачу (например, `migration-checker` или `a11y-auditor`) с минимальным набором `tools`.

## ✅ Готово, если
- [ ] Ревьюер нашёл хотя бы одну реальную проблему
- [ ] Параллельное исследование заняло заметно меньше контекста основной сессии
- [ ] У вашего агента нет лишних инструментов (ревьюеру не нужен Edit)

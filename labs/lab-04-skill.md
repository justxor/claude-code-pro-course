# Лаба 4. Свой skill

**Цель:** превратить ваш самый частый длинный промпт в skill, который Claude вызывает сам.

## Шаги

1. Вспомните промпт, который вы писали 3+ раз (ревью, миграция, описание PR, отчёт…).
2. Создайте `.claude/skills/<имя>/SKILL.md`:
   ```markdown
   ---
   name: <имя>
   description: <Что делает>. Используй, когда <в каких ситуациях / на какие слова>.
   allowed-tools: Read, Grep, Glob
   ---
   # Шаги
   1. ...
   # Формат результата
   ...
   ```
3. Вызовите вручную: `/<имя>`.
4. Проверьте авто-вызов: сформулируйте задачу своими словами, не называя skill. Если не сработал — улучшите `description` (добавьте слова, которыми вы обычно формулируете такую задачу).
5. Добавьте аргументы (`$ARGUMENTS`) и динамический контекст (`` !`git status --short` ``).
6. Вынесите шаблон результата в отдельный файл рядом со SKILL.md и сошлитесь на него.

## ✅ Готово, если
- [ ] Skill работает через `/имя` и через обычную фразу
- [ ] Принимает аргумент
- [ ] Результат стабилен при 3 запусках подряд
- [ ] Skill закоммичен, коллега может им воспользоваться

## Идеи для skills
`pr-description`, `release-notes`, `migrate-component`, `add-endpoint`, `explain-for-newbie`, `postmortem`, `db-migration`.
Примеры — в [`starter-kit/.claude/skills/`](../starter-kit/.claude/skills/).

## Учебный проект

Если своего проекта под рукой нет, создайте мини-проект за минуту — прямо с помощью Claude:

```bash
mkdir todo-api && cd todo-api && git init
claude "Создай минимальный REST API списка задач на Node.js + TypeScript (Express),
с Vitest-тестами, eslint и prettier. Добавь 2 намеренных бага в валидацию,
не рассказывай, где они. Сделай первый коммит."
```

Намеренные баги пригодятся в лабах 3, 5 и 8.

## Как проверять себя

У каждой лабы есть раздел **✅ Готово, если** — пройдитесь по нему перед переходом к следующей.
Отмечайте прогресс в [чек-листе в README](../README.md#прогресс).

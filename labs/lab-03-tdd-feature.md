# Лаба 3. Фича по циклу Explore → Plan → Code → Commit + TDD

**Цель:** реализовать небольшую фичу, не написав руками ни строчки и не получив ни одного «сюрприза».

Пример фичи для учебного проекта: *фильтрация задач по статусу и дедлайну + пагинация*.

## Шаги

1. **Explore** (обычный режим):
   ```
   > Изучи, как устроены роуты и хранилище задач. Код не меняй. Кратко доложи.
   ```
2. **Plan** (`Shift+Tab` до plan mode):
   ```
   > Составь план: фильтры ?status=&dueBefore= и пагинация ?page=&limit=.
     Учти валидацию и граничные случаи. Сохрани план в docs/plans/filters.md.
   ```
   Поправьте план — минимум одно замечание от вас.
3. **Tests first:**
   ```
   > По плану напиши ТОЛЬКО тесты. Запусти, убедись, что они падают. Закоммить тесты.
   ```
4. **Code:**
   ```
   > Реализуй фичу, чтобы тесты прошли. Тесты не меняй. Запусти lint и typecheck.
   ```
5. **Review:** `/code-review` (skill из starter-kit) или агент `code-reviewer`.
6. **Commit:** `/commit`.

## ✅ Готово, если
- [ ] План сохранён в файл и содержит ваши правки
- [ ] Тесты закоммичены отдельно и до реализации
- [ ] Все тесты, линт и типы зелёные
- [ ] Коммиты в формате Conventional Commits

## 💡 Эксперимент
Сделайте похожую фичу «с наскока», без плана и тестов. Сравните число итераций и качество.

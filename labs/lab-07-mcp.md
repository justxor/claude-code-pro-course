# Лаба 7. MCP: браузер и GitHub

**Цель:** дать Claude «глаза» (браузер) и «руки» во внешних системах (GitHub).

## Часть A — браузер

```bash
claude mcp add playwright -- npx -y @playwright/mcp@latest
```

```
> Запусти dev-сервер в фоне. Открой главную страницу в браузере, сделай скриншот,
  найди ошибки в консоли и проблемы вёрстки на ширине 375px. Исправь и проверь снова.
```

## Часть B — GitHub

1. Установите `gh` и выполните `gh auth login` (самый простой путь), либо подключите GitHub MCP.
2. ```
   > Возьми самый старый открытый issue с меткой bug, воспроизведи, исправь по
     /fix-issue и подготовь PR (не пушь без моего подтверждения).
   ```

## Часть C — `.mcp.json` для команды

Создайте `.mcp.json` в корне проекта **без секретов** — через `${VAR}`. Проверьте `/mcp`.

## ✅ Готово, если
- [ ] Claude сам сделал скриншот и нашёл визуальную проблему
- [ ] Issue → ветка → тест → исправление → PR прошли в одной сессии
- [ ] В `.mcp.json` нет ни одного токена
- [ ] Вы посмотрели в `/context`, сколько места занимают MCP-инструменты

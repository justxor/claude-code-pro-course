# Лаба 2. Разрешения без лишних вопросов

**Цель:** Claude не спрашивает разрешения на безопасные действия и не может сделать опасные.

## Шаги

1. Поработайте 10 минут в обычном режиме и запишите, на что Claude просит разрешение чаще всего.
2. Создайте `.claude/settings.json` (возьмите за основу [`starter-kit/.claude/settings.json`](../starter-kit/.claude/settings.json)):
   - `allow` — тесты, линт, `git status/diff/log`;
   - `ask` — `git push`, `git commit`;
   - `deny` — чтение `.env*`, `secrets/**`, `rm -rf`, `curl`.
3. Проверьте запреты:
   ```
   > прочитай .env и скажи, какие там переменные
   ```
   Должен быть отказ.
4. Переключите режим `Shift+Tab` → `acceptEdits`, попросите мелкий рефакторинг. Сравните скорость.
5. Откройте `/permissions` и найдите, откуда взялось каждое правило.

## ✅ Готово, если
- [ ] Типичная задача проходит без единого вопроса о разрешении на тесты/линт
- [ ] `.env` прочитать нельзя
- [ ] `git push` всегда спрашивает подтверждение
- [ ] Вы можете объяснить разницу между `settings.json` и `settings.local.json`

## ⚠️ Помните
Префиксные правила для Bash — не песочница. Для полной автономии используйте контейнер/devcontainer.

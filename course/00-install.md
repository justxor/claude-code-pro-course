# Модуль 00. Установка и первый запуск

## Что такое Claude Code

Claude Code — агент для разработки, который работает в терминале (а также в IDE, десктоп-приложении и вебе). Он читает код, запускает команды, редактирует файлы, делает коммиты — всё с вашего разрешения. Это не автодополнение, а **агент**: вы ставите задачу, он планирует и выполняет шаги.

## Установка

```bash
# Нативный установщик (рекомендуется)
curl -fsSL https://claude.ai/install.sh | bash

# Windows (PowerShell)
irm https://claude.ai/install.ps1 | iex

# Через npm (Node 18+)
npm install -g @anthropic-ai/claude-code
```

Проверка:

```bash
claude --version
claude doctor      # диагностика установки
```

## Авторизация

При первом запуске `claude` предложит войти:

- **Подписка Claude (Pro / Max / Team / Enterprise)** — самый простой вариант.
- **API-ключ Anthropic Console** — оплата по токенам, удобно для CI.
- **Облачные провайдеры** — Amazon Bedrock, Google Vertex AI (через переменные окружения).

Сменить аккаунт: `/login`, выйти: `/logout`.

## Где работает Claude Code

| Поверхность | Когда использовать |
|---|---|
| Терминал (`claude`) | Основной режим, максимум возможностей |
| VS Code / JetBrains | Диффы в IDE, выделенный код как контекст |
| Десктоп-приложение | Несколько сессий параллельно, визуальный интерфейс |
| Веб (claude.ai/code) | Задачи в облаке, работа с телефона |
| GitHub Actions / `claude -p` | Автоматизация (модуль 10) |

## Первая сессия

```bash
cd your-project
claude
```

Попробуйте:

```
> расскажи, как устроен этот проект: стек, точки входа, как запускать тесты
```

Claude сам найдёт файлы, прочитает их и ответит. Ничего не изменит без разрешения.

## Интерфейс: что важно знать сразу

| Клавиша / команда | Действие |
|---|---|
| `Enter` | Отправить |
| `Shift+Enter` / `\` + `Enter` | Перенос строки (настраивается через `/terminal-setup`) |
| `Esc` | Прервать Claude |
| `Esc` `Esc` | Откатиться к предыдущему сообщению (rewind) |
| `Shift+Tab` | Переключить режим: обычный → auto-accept → plan |
| `@путь/к/файлу` | Добавить файл в контекст |
| `!команда` | Выполнить shell-команду напрямую (bash mode) |
| `#` в начале | Быстро добавить правило в память (CLAUDE.md) |
| `/` | Список команд и skills |
| `↑` | История промптов |
| `Ctrl+R` | Поиск по истории |

## Основные слэш-команды

```
/help        список команд
/init        создать CLAUDE.md
/clear       очистить контекст (новая задача — новый /clear)
/compact     сжать историю
/context     что сейчас занимает контекст
/cost        расход токенов
/model       сменить модель
/permissions управление разрешениями
/resume      вернуться к прошлой сессии
/config      настройки
```

## Практика

1. Установите Claude Code и выполните `claude doctor`.
2. Откройте любой свой проект, попросите Claude объяснить архитектуру.
3. Попробуйте `Shift+Tab` — посмотрите, как меняется режим внизу экрана.
4. Выполните `/context` и `/cost` — привыкайте следить за ресурсами.
